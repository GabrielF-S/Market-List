# Market List

## Projeto feito para controle de lista de compras mensais do mercado

O Intuito da aplicação é um Backend em Java, uma base de Dados Postgres e o Frontend em Angular, que estará disponível
em outro repositório, onde poderemos adicionar o nome, a quantidade e o valor dos itens na lista, para controlarmos os 
gastos no mercado, assim como acompanhar listas anteriores para comparação de valores e reutilização de itens na lista
